Agent-6：可靠性护栏 —— 让 7B 小模型也能稳定跑完

对应代码：llm.py、codesage.py、assetsage.py、graph.py、tests/test_smoke.py
LLM 一定会出错：输出坏 JSON、重复调用、死循环、依赖挂掉。可靠性 = 每一层都有兜底，错误变成可处理的数据，而不是崩溃。

图 1：越靠外，兜住的故障越大

2. 故障 → 护栏 对照表

故障护栏位置

3. 去重 + 熔断的执行流程

图 2：去重是「软拒绝」（让 LLM 换方向），熔断是「硬停止」

4. 可复现与可测试

  • 可复现：temperature = 0；每次调用写入 state.tool_calls；--dump-trace 导出完整轨迹。
  • 可测试：tests/test_smoke.py 不依赖真实 LLM，用 mock 验证强制路由、State 流转、MCP 不可达时的降级。
图 3：把「不稳定的 LLM」替换成 mock，单独验证确定性逻辑

5. 你该记住的 3 件事

  1. 每个循环都要有上限，每个失败都要有兜底输出（不丢已有证据）。
  2. 错误当作数据回灌给 LLM，而不是抛异常中断。
  3. 把确定性逻辑和 LLM 分开，才能写不依赖模型的测试。
