Agent-5：代码索引 —— SQLite + ripgrep 分工

对应代码：shared/explorer_bridge.py、agents/codesage.py
索引回答「它在哪定义」，ripgrep 回答「谁在用它」，read_file 回答「具体怎么写」。三者组合，让 LLM 不用把整个 UE 源码塞进上下文。

1. 为什么不能直接让 LLM 读源码

  • UE 源码是百万行级，远超上下文窗口（本项目 num_ctx 才 8192）。
  • 所以 Agent 必须按需检索：先定位 → 再读一小段 → 再追下去。

4. 工程细节（面试加分点）

问题处理位置

5. 你该记住的 3 件事

  1. 大代码库 = 先建索引再检索，不要指望上下文装得下。
  2. 索引（精确定位）+ ripgrep（全文关系）+ 窗口读取（细节），各管一段。
  3. 对数据 schema 做自适应与降级，工具才能在不同版本的库上都能跑。
